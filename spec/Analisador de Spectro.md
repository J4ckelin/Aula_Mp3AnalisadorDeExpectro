# analisador de spectro de arquivos mp3 e equalizador
## contexto 
crie uma **aplicação SPA**, ou seja, **Single Page Aplication**, para analisar spectro de arquivos em MP3 com equalizador de som

## especificações/requisitos 
1. o usuário seleciona um arquivo do seu próprio dispositivo.
2. executa um "play" 
3. O analisador inicia a renderização dos gráficos.
4. Abaixo dos gráficos o usuário terá acesso a um relatório brevemente descritivo. 
5. adicione botões para equalizar o áudio, com variações para alterar o volume dos baixos da música, os tons agudos e assim por diante. 

## Recursos adicionais
1. permita  alterar a frequência de Hz da música que estiver em execução para outras frequências populares da terapia alternativa. 
2. permita salvar o arquivo com a nova frequência adicionada. 
3. adicione botões em formato de fader inspirados em uma mesa de som, um controle deslizante que altera o volume do som e ajusta o nível de áudio

## Stack 
* Html, CSS e JS puro (Vanilla)
* Utilize bibliotecas populares para reduzir códigos, erros e manutenção. 
* vou hospedar no Git Pages

## UI / UX
* Mobile First 
* Interfaces minimalistas com tons neutros e pastéis, com estética limpa e moderna
* Efeitos animados sutis em botões e outros componentes 
* utilize cores diferentes utilizando psicologia das cores para alterar conforme a opção do usuário
* Faça opção para modo escuro ainda na estética limpa, moderna e minimalista. Na opção de modo escuro as cores se tornam vibrantes, com uma estética mais moderna e tech
* Na renderização dos gráficos adicione uma animação ritmada conforme o áudio

## Instruções para agentes de IA
1. analise **sempre** a viabilidade do desenvolvimento
2. não havendo viabilidade, **não execute** a tarefa e solicite interação humana
3. todo ajuste, correção, incrementação, **registre** em um arquivo de back log. Salve o arquivo em /spec/backlog.md registrando a data, a hora, e a tarefa executada.
